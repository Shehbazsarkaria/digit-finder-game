Digitfinder Guide

For Players

How to Play:

  • Think of a secret number between 0-100
  • Computer asks yes/no questions to guess it
  • Answer: Yes, No, or Not Sure

Question Types:

  • Math: "Is it even?", "Multiple of 10?"
  • Range: "Greater than X?"
  • Trivia: "Meme numbers" or "Pointy digits"

Winning:

  • You win if computer runs out of guesses
  • Computer wins if it guesses correctly

For Developers

Setup:

  • Install Node.js
  • Run: npm install express
  • Run: node server.js

    • Note: The backend runs on port 8000. Proceed to http://localhost:8000/homePage.html to run the game.

Tech Stack:

  • Backend: Express.js (JSON storage)
  • Frontend: Vanilla JS / SPA Architecture
