# 🔢 Digit Finder

An interactive number-guessing game where the computer tries to guess your secret number between 0-100 using a mix of binary search, trivia, and filter questions.

## 🎮 How to Play

1. Think of a number between 0-100
2. Answer the computer's yes/no questions
3. The computer will try to guess your number within 10 questions
4. You win if it runs out of guesses!

## 🛠️ Tech Stack

- **Backend:** Node.js + Express.js
- **Frontend:** Vanilla JavaScript (SPA architecture)
- **Storage:** JSON file persistence
- **Testing:** Vitest
